# Зеркало для установки Dash to Dock в России (Fedora / GNOME)

Это независимое зеркало создано для того, чтобы пользователи Linux из России могли установить популярное расширение **Dash to Dock** без использования VPN, обходя блокировки официального сайта GNOME Extensions.

## Быстрый запуск одной командой
Просто откройте терминал вашей Fedora (или любого другого дистрибутива с GNOME) и выполните следующую команду:

```
bach curl -sSL https://githubusercontent.com | bash
```
